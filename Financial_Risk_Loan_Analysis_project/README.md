# Financial Risk & Loan Analysis Dashboard – Power BI

## Project Overview
This Power BI dashboard analyzes customer demographics, loan portfolio performance, and financial risk trends using interactive visualizations and KPI monitoring.

## Tools Used
- Power BI
- DAX
- Power Query
- Excel

## Dashboard Pages

### 1. Customer Demographics
- Customer distribution by gender and education
- Credit score analysis
- Income segmentation
- Average income and age analysis

### 2. Loan Portfolio & Performance
- Loan type distribution
- Interest rate analysis
- Active vs defaulted loans
- Top loan amount analysis

### 3. Financial Risk Analysis
- Defaulted loan analysis
- High-risk customer identification
- Employment and income-based risk segmentation
- Credit score risk distribution

## Key Features
- KPI Cards
- Donut & Pie Charts
- Gauge Visual
- Matrix Reports
- Conditional Risk Categorization
- Interactive Slicers

## Business Insights
- Identified high-risk customers based on credit score.
- Analyzed defaulted loan patterns.
- Evaluated loan performance across customer segments.
- Improved financial risk visibility through dashboards.
