# Financial Risk & Loan Analysis — Power BI

## Overview
Interactive 3-page Power BI dashboard analyzing loan portfolio performance,
customer demographics, and financial risk trends.

## Problem Statement
Financial teams needed a unified view of loan risk, default patterns,
and customer credit behavior for better decision-making.

## Tools Used
- Power BI (DAX, Power Query, KPI cards, gauge visuals, donut charts)
- Excel (source data preparation)

## Key Findings
- Identified high-risk customers using credit score categorization
- Built risk segmentation dashboard with conditional categories
- Analyzed defaulted loan patterns across demographics

## How to Use
Download the .pbix file and open in Power BI Desktop.
